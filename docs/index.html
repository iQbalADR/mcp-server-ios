Overview

This project creates a Model Context Protocol (MCP) server that bridges your local AI with Xcode's coding assistant.

🤖

Code-Optimized LLM

Qwen2.5-Coder-7B trained specifically on code, with 16K context window.

🔧

Xcode AI Assistant

Seamlessly integrates with Xcode 26.x's built-in AI features via MCP protocol.

🧠

RAG + Re-Ranking

LanceDB vector search with ms-marco cross-encoder re-ranking for precise results.

🏷️

Auto-Labeling

Automatically categorizes code (ui, networking, tests, etc.) for filtered search.

🔒

Fully Local

Everything runs on your machine. No cloud dependencies, complete privacy.

⚡

Action Tools

Agentic capabilities: File writing, command execution, and autonomous exploration.

Quick Start

Prerequisites: Xcode 26.x, Ollama, Python 3.10+

  1. Run Setup Script

    ./scripts/setup.sh

    Creates virtual environment, installs dependencies, pulls models.

  2. Create Custom Models

    ./scripts/create_models.sh

    Pulls Qwen2.5-Coder-7B and creates specialized iOS models.

  3. Ingest Your Project

    python scripts/ingest_project.py /path/to/your/project

    Adds your codebase to the vector database for context.

  4. Start the HTTP Server

    ./scripts/start_http_server.sh

    Starts the OpenAI-compatible HTTP server on port 1234 for Xcode.

  5. Verify It's Working

    curl http://localhost:1234/health
curl http://localhost:1234/v1/models
curl http://localhost:1234/mcp/stats

    Or use MCP Inspector: npx @anthropic-ai/mcp-inspector ./venv/bin/python -m server.mcp_server

Note: Native Xcode MCP integration requires a future Xcode version with MCP support. For now, use the MCP Inspector or run the server directly for testing.

Agent Features

The server includes agent-loop capabilities that make it more than just a chat interface.

⏳

Instant Feedback

Sends an immediate "Processing..." indicator before any RAG or model calls, eliminating perceived latency.

🔍

RAG Context Injection

Automatically searches the vector database for relevant code snippets and injects them as context.

🔨

Xcode Build Tool

Auto-detects workspaces, schemes, and runs xcodebuild with output truncation (50 lines).

📝

Configurable System Prompt

Customize AI personality and formatting via config.yaml — no code changes needed.

The "notebook" uses LanceDB to maintain persistent memory across sessions.

Docs

Configuration

Edit config.yaml to customize the server:

System Prompt 🆕

New: Customize the AI's personality and formatting rules directly in config.yaml. Restart the server to apply changes. 
system_prompt: |
  You are a Senior iOS Engineer and Xcode AI Assistant.
  # Formatting rules, few-shot examples, tool usage instructions
  # Edit this to customize AI behavior without touching code

Ollama Settings

ollama:
  base_url: "http://localhost:11434"
  chat_model: "ios-qwen-coder"         # Qwen2.5-Coder-7B
  embedding_model: "nomic-embed-text:v1.5"
  temperature: 0.1
  max_tokens: 4096

Labels (Auto-Labeling)

labels:
  auto_detect: true    # Auto-label by path, content, extension
  path_rules:
    - pattern: "MyFeature/"
      labels: ["feature-x"]
  content_rules:
    - pattern: "import SpecialLib"
      labels: ["special"]

LanceDB Settings

lancedb:
  db_path: "./data/lancedb"
  max_results: 10
  similarity_threshold: 0.7

Debug Settings

debug:
  enabled: true
  save_requests: true
  request_log: "./logs/requests.jsonl"
